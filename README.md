# MORES: A Radiative Transfer-Based Moon Regolith Scattering Model

MORES is a computational model grounded in radiative transfer theory, designed to simulate the scattering properties of lunar regolith, considering factors such as surface roughness and the presence of rocks. It offers valuable insights into the interaction of electromagnetic waves with the Moon's surface, supporting the interpretation of lunar synthetic aperture radar (SAR) remote sensing data.
